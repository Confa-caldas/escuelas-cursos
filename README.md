# Cursos y escuelas 

Este proyecto fue generado con [Angular CLI](https://github.com/angular/angular-cli) version 17.3.12

## Autor

Proyecto creado por tec_karena

## Servidor de desarrollo

Ejecute `ng serve` para un servidor de desarrollo. Navegue a `http://localhost:4200/`. La aplicación se recargará automáticamente si cambia alguno de los archivos fuente.

## Andamiaje de código

Ejecute `ng generate component component-name` para generar un nuevo componente. También puede usar `ng generate Directive|pipe|service|class|guard|interface|enum|module`.

## Compilación

Ejecute `ng build` para compilar el proyecto. Los artefactos de compilación se almacenarán en el directorio `dist/`. Use el el comando `ng build --configuration production`   para una compilación de producción.
